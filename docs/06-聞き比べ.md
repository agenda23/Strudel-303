# 6. フィルタの聞き比べ（A/B）

`tbfilter("tpt")`（従来、既定）と `tbfilter("diode")`（回路から導いた非線形モデル）を、同じフレーズで聴き比べるためのトラックです。

## サンプル
- `docs/examples/filter-ab-compare.js`（48 小節、136 BPM、A マイナー。約 85 秒）。コードをエディタに貼って **EVAL** で再生します。
- 4 小節ごとに条件が変わり、各条件で **tpt 2 小節 → diode 2 小節** の順に鳴ります。
- 切り替えの合図: 各区間の 1 拍目に **リムが 1 回 = tpt、2 回 = diode**。
- 条件ごとに音量を揃えてあるので、音色の違いだけを聴けます（`.gain` で調整。小節ごとの RMS を測って合わせました）。

| 小節 | 条件 | 聴きどころ |
| --- | --- | --- |
| 1〜4 | ベースライン（cutoff 600、res 0.88） | モデルそのものの違い。diode は同じ `tbcut` で暗めのはず |
| 5〜8 | 飽和を強く（tpt drive 0.6 / diode 0.7） | 強く弾いたときの圧縮、倍音の増え方。丸くなりすぎないか |
| 9〜12 | レゾナンス 0.6 | 中程度のレゾナンスでのピークの出方 |
| 13〜16 | レゾナンス 0.95 | 最大付近の鳴り。ピークの強さ、低音の残り方 |
| 17〜20 | カットオフのスイープ（600 → 2800、2 小節） | うなりの動き。ここが一番「acid 感」を判断しやすい |
| 21〜24 | アクセントを 1 つおきに | アクセントでの音量・フィルタの開き方 |
| 25〜28 | 矩形波 | 矩形波の質感の差 |
| 29〜32 | 歪み（RAT 0.4） | 歪みとの組み合わせ |
| 33〜36 | **オクターブのスライド**（±1 オクターブを次の音へ滑る） | 303 の特徴的な奏法。ピッチが動く間もフィルタが鳴り続けるか、エンベロープが再発音されないか |
| 37〜40 | **2 オクターブのスライド**（A1 ↔ A3） | 大きな跳躍でのスライド。滑りながらフィルタが開いたままか、うなりが途切れないか |
| 41〜44 | **ゆっくりしたグライド**（`tbslidetime` 0.15。次のステップまでに滑り切らない） | 実機の「ずるっ」としたスライド感。滑り切る前に次の音が来たときの挙動 |
| 45〜48 | **アクセント + 連続スライド**（ほぼ全ステップがスライドでつながるレガートのラン） | アクセントがスライド先で効くか、つながった音のうなりの連続性 |

スライドは「そのステップから**次の隣接するステップ**へ」滑ります。間に休符 `~` があると、スライドではなく通常の発音になります（サンプルの音列は休符なしにしてあります）。

## 判断のしかた
1. 各ペアで、どちらが「それらしい」か（うなり、低音の太さ、アクセントのパンチ）を選びます。
2. スライドの区間（33〜48 小節）では、ピッチが動いている間のうなり・音量・アクセントの出方を比べます。
3. `diode` が暗い場合は `tbcut` を上げて合わせます（`diode` の `tbcut` はレゾナンスのピーク周波数です）。
4. 飽和が足りなければ `tbdrive` を上げます。強すぎてレゾナンスが丸くなる場合は下げます。
5. 気に入った組み合わせ（モデル、`tbdrive`、`tbcut` の倍率）を教えてください。既定値に反映します。

## 補足
- 同じ区間を繰り返したいときは、`<...>` のリストから他の条件を消します。
- 数値の根拠と未確認事項は `spec/定数記録.md` を参照してください。


## 第 2 ラウンド（`docs/examples/filter-ab-compare-2.js`）

第 1 ラウンドの感想（tpt は派手だが嘘くさい / diode はそれっぽいが地味で遠い）を受けて、diode を調整しました。

**測定で分かったこと**（`tools/band-profile.ts`、同じフレーズの周波数帯ごとのエネルギー）
- diode の飽和は、**高域を削る**方向に働いていました（`tbdrive` 0.3 で 1.6〜3.2kHz が約 5dB、0.7 で約 9dB 低下）。倍音が増えず、丸くなって「地味」になっていた原因です。
- そこで、(1) 飽和の既定を弱めて（0.1）、(2) **ダイオード対の非対称**（`tbasym`）を追加しました。非対称は偶数次の倍音を作り、200Hz〜3.2kHz を 4〜6dB 持ち上げます（芯と「噛みつき」）。高域を削りません。

| 合図（リム） | 設定 |
| --- | --- |
| 1 回 | `tpt`（従来） |
| 2 回 | diode-1: 第 1 ラウンドの設定（`tbdrive` 0.3、非対称なし） |
| 3 回 | diode-2: **新しい既定**（`tbdrive` 0.1、`tbasym` 0.5） |
| 4 回 | diode-3: さらに噛みつく（`tbdrive` 0.1、`tbasym` 1.0） |

状況は 4 つ（各 8 小節 = 4 バリアント × 2 小節）: ベースライン／カットオフのスイープ（**ノブレーンで連続操作**）／アクセントとオクターブスライド／レゾナンス 0.95 と連続スライド。音量はバリアントごとに揃えてあります。

聴いて、**どれが一番それらしいか**（嘘くさくなく、地味でもない）を教えてください。足りなければ、`tbasym`（0〜1）と `tbdrive`（0〜1）の組み合わせを決めて、既定値に反映します。


## 第 3 ラウンド: 音ごとの連続性（`docs/examples/continuity-ab.js`）

**フィードバック**: 「実機に比べて音ごとの連続性がない」。**原因（測定）**: 直近のトラックが `legato(0.5)`・リリース 15ms・短いディケイで、音と音の間の約 21% が −30dB 未満の無音でした（`legato(0.85)` では 0%）。

2 つの場面（プレーンなライン／スライドの連続）で、各 5 バリアントを 2 小節ずつ、1 拍目のリムの回数で区別して鳴らします。音量は揃えてあります。

| リム | 設定 |
| --- | --- |
| 1 回 | 直近のトラックの設定（`legato` 0.5、リリース 15ms、ディケイ 0.2） |
| 2 回 | `legato` 0.85、ディケイ 0.5 |
| 3 回 | 上 + リリース 30ms（`tbrel(0.03)`） |
| 4 回 | 上 + 音程の滑らかさ 6ms（`tbglide(0.006)`） |
| 5 回 | 最も連続的（`legato` 0.92、ディケイ 0.8、リリース 40ms、グライド 8ms） |

聴いて、どこから「実機っぽいつながり」になるかを教えてください。それを既定値（`legato` の既定、`tbrel`、`tbglide`）に反映します。既存の 2 トラック（`hamburg-acid-138.js`、`hardfloor-knobs-136.js`）は、先に連続側の設定（`legato` 0.85、リリース 30ms、グライド 6ms、ディケイ 0.8 → 0.45）に更新済みです。


## 第 4 ラウンド: ポルタメントの感じ（`docs/examples/portamento-ab.js`）

**フィードバック**: 「decay は伸びたが、実機はポルタメントが効いているように聞こえる。こちらは別々の音が切れ目なく鳴っている印象」。

**測定で分かったこと**
- スライドが**周波数（Hz）の空間**で指数的に動いていました。実機の RC は音程制御電圧（半音の空間）にかかるので、形が違います。オクターブ上がりは半分まで **10.7ms**、下がりは **17.6ms** と、上下で非対称でした。
- 長さが 60ms 前後に限られ、試せる選択肢が少なかった。

**変更**: スライドを半音の空間（`tbslidecurve("log")`、既定）にし、上下で対称になりました（テストで確認）。`tbslidetime` で 0.24 秒まで長くできます。

30 小節（3 場面 × 5 バリアント × 2 小節）。1 拍目のリムの回数で区別します。

| リム | 設定 |
| --- | --- |
| 1 回 | 旧: Hz 空間のグライド、60ms |
| 2 回 | 半音空間、60ms |
| 3 回 | 半音空間、100ms（スライドしない音にも 10ms の滑らかさ） |
| 4 回 | 半音空間、160ms（同 20ms） |
| 5 回 | 半音空間、240ms（同 40ms）。強いポルタメント |

場面: スライドの連続ラン／オクターブ跳躍のスライド／**全ステップがスライド**（純粋なポルタメントのライン）。

聴いて、**実機の「ポルタメントが効いた感じ」に近いのは何回目か**を教えてください。それを既定値（`tbslidetime`、`tbglide`）にします。
