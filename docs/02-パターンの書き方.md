# 2. パターンの書き方

Strudel のパターン言語そのものです。303 は `.s("tb303")` を付けるだけで、他のサウンドと同じように扱えます。

## 基本形

```javascript
setcps(138/60/4)

$: n("0 0 12 7 ~ 3 5 0").scale("c2:minor")
  .s("tb303")
  .accent("0 1 0 0 0 1 0 0")
  .slide("0 0 1 0 0 0 1 0")
  .tbcut(sine.range(280, 3400).slow(4))
  .tbres(0.85)
  .tbenv(0.68)
  .tbdec(0.24)

$: s("bd*4, ~ cp ~ cp").bank("RolandTR909")
$: s("hh*8, [~ oh]*4").bank("RolandTR909").cut(1)
```

- `$:` ごとに別のトラックです。`_$:` で行頭に付けるとそのトラックをミュートできます。名前付き（`acid:`）や `.p("acid")` も使えます。
- `~` は休符、`*4` は繰り返し、`.slow(4)` は 4 サイクルかけて変化、など Strudel のミニ表記がそのまま使えます。

## 音程

| 書き方 | 意味 |
| --- | --- |
| `note("c2 eb2 g2")` | 音名で指定（Strudel と同じ。`c3` = MIDI 48） |
| `n("0 3 7").scale("c2:minor")` | スケール上の度数。最も一般的 |
| `freq(110)` | 周波数（Hz）で指定 |
| `.octave(1)` | 1 オクターブ上 |
| `n("0 12")`（`scale` なし） | 「C2 からの半音数」として鳴ります（初回のみ警告）。Strudel の標準の意味とは違うので `scale` か `note` の利用をおすすめします |

303 の実用音域は C1〜C3 付近です。`f1:minor`、`c2:minor`、`d2:phrygian` などが定番です。

## 303 専用コントロール

| コントロール | 範囲 | 説明 |
| --- | --- | --- |
| `.accent("1 0 ...")` | 0 / 1 | アクセント。音量が増し、フィルタが強く開く。連続すると効きが蓄積（アクセントスイープ） |
| `.slide("1 0 ...")` | 0 / 1 | そのステップから**次のステップ**へピッチだけ滑る。エンベロープは再トリガーされない |
| `.tbcut(...)` | 50〜8000 Hz | カットオフの基準値。`sine.range(300, 3000).slow(4)` のように動かすのが定番 |
| `.tbres(...)` | 0〜1 | レゾナンス。0.8 以上でアシッドらしいうなり |
| `.tbenv(...)` | 0〜1 | Env Mod。エンベロープでカットオフをどれだけ開くか |
| `.tbdec(...)` | 0.1〜2 秒 | フィルタ・エンベロープのディケイ。短い＝パキパキ、長い＝うねる（アクセント時は少し短くなる） |
| `.tbwave(...)` | `"saw"` / `"square"` | 波形 |
| `.tbslidetime(...)` | 秒（既定 0.06） | スライドにかかる時間 |
| `.tbdist(...)` | 0〜1 | 歪みの量 |
| `.tbdisttone(...)` | 0〜1 | 歪みのトーン（低い＝暗い） |
| `.tbdistmix(...)` | 0〜1 | 歪みのウェット／ドライ |
| `.tbdisttype(...)` | `"rat"` / `"tube"` / `"fuzz"` | 歪みの種類 |

コントロールに値が書かれていないノートは既定値に戻ります（前のノートの値が残ることはありません）。

### スライドの仕組み

```javascript
.slide("0 0 1 0 0 0 1 0")
```

3 番目のステップに `1` があると、3 番目の音から 4 番目の音へ滑ります。次のノートがすぐ続くときだけ有効で、間に休符 `~` があると通常の発音になります。

## Strudel 標準コントロールとの関係

| コントロール | 303 での扱い |
| --- | --- |
| `gain` `velocity` `postgain` `pan` `orbit` `duck…` など | Strudel の標準処理がそのまま掛かる |
| `lpf` `hpf` `shape` など | 303 内蔵フィルタの**後ろ**に掛かる。303 のフィルタは `tbcut` / `tbres` で操作する |
| `clip` `legato` | 音の長さ（既定は 0.85。1 に近いほどつながる） |
| `attack` `release` `sustain` | 無視される |
| `delay` `room` | 使えるが、プリセットでは使っていない |

## 909 ドラム

```javascript
$: s("bd*4, ~ cp ~ cp").bank("RolandTR909")
$: s("hh*8, [~ oh]*4").bank("RolandTR909").cut(1)
```

- ハイハットの開閉を切り替えるには `.cut(1)` を **ハイハット系だけ**に掛けます。キックやクラップと同じブロックに掛けると、ハイハットが鳴るたびに切られます。
- ドラムの音は初回にネットから取得します。オフラインだと鳴りません。

## アシッドのコツ

- **まず 16 ステップ**: `n("0 0 12 7 ~ 3 5 0 0 12 10 7 ~ 5 3 0")` のように 16 ステップで考えると 303 らしくなります。
- **同じ音を繰り返し、時々オクターブ上**（`12`）。メロディを動かしすぎない。
- **accent は 2〜4 個**、**slide は 1〜3 個**を目安に。
- **tbcut を LFO でゆっくり動かす**（`.slow(4)`〜`.slow(16)`）。ライブ中に手で書き換えるのも定番。
- **tbres は 0.8〜0.92**、**tbenv は 0.5〜0.8**、**tbdec は 0.15〜0.3** が出発点。
- 音が痩せたら `tbdist` を 0.3 前後から足す。
