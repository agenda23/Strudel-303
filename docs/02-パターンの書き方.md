# 2. パターンの書き方

Strudel のパターン言語そのものです。303 は `.s("tb303")` を付けるだけで、他のサウンドと同じように扱えます。

## 基本形

```javascript
setcps(138/60/4)

$: n("0 0 7 4 ~ 2 3 0").scale("c2:minor")
  .s("tb303")
  .accent("0 1 0 0 0 1 0 0")
  .slide("0 0 1 0 0 0 1 0")
  .tbcut(sine.range(280, 3400).slow(4))
  .tbres(0.85)
  .tbenv(0.68)
  .tbdec(0.24)

$: s("bd*4, ~ cp ~ cp").bank("RolandTR909").gain(0.7)
$: s("hh*8, [~ oh]*4").bank("RolandTR909").gain(0.45).cut(1)
```

- `$:` ごとに別のトラックです。`_$:` で行頭に付けるとそのトラックをミュートできます。名前付き（`acid:`）や `.p("acid")` も使えます。
- `~` は休符、`*4` は繰り返し、`.slow(4)` は 4 サイクルかけて変化、など Strudel のミニ表記がそのまま使えます。

## 音程

| 書き方 | 意味 |
| --- | --- |
| `note("c2 eb2 g2")` | 音名で指定（Strudel と同じ。`c3` = MIDI 48） |
| `n("0 2 4").scale("c2:minor")` | **スケール上の度数**（0 = ルート、7 = 1 オクターブ上。7 音階の場合）。最も一般的。`12` は「12 度上」で、約 1 オクターブ半上になるので注意 |
| `freq(110)` | 周波数（Hz）で指定 |
| `.octave(1)` | 1 オクターブ上 |
| `n("0 12")`（`scale` なし） | 「C2 からの半音数」として鳴ります（初回のみ警告）。Strudel の標準の意味とは違うので `scale` か `note` の利用をおすすめします |

303 の実用音域は C1〜C3 付近です。`f1:minor`、`c2:minor`、`d2:phrygian` などが定番です。

## 303 専用コントロール

| コントロール | 範囲 | 説明 |
| --- | --- | --- |
| `.accent("1 0 ...")` | 0 / 1 | アクセント。音量が増し、フィルタが強く開く。連続すると効きが蓄積（アクセントスイープ） |
| `.slide("1 0 ...")` | 0 / 1 | そのステップから**次のステップ**へピッチだけ滑る。エンベロープは再トリガーされない |
| `.tbcut(...)` | 50〜8000 Hz | カットオフの基準値。`sine.range(300, 3000).slow(4)` のように動かすのが定番 |
| `.tbres(...)` | 0〜1 | レゾナンス。0.8 以上でアシッドらしいうなり |
| `.tbenv(...)` | 0〜1 | Env Mod。エンベロープでカットオフをどれだけ開くか |
| `.tbdec(...)` | 0.1〜2 秒 | フィルタ・エンベロープのディケイ。短い＝パキパキ、長い＝うねる（アクセント時は少し短くなる） |
| `.tbwave(...)` | `"saw"` / `"square"` | 波形 |
| `.tbslidetime(...)` | 秒（既定 0.06） | スライドにかかる時間（目標音程の 95% に着くまで）。長くすると（0.1〜0.25）次の音までに滑り切らず、ポルタメントのように聞こえる |
| `.tbdist(...)` | 0〜1 | 歪みの量 |
| `.tbdisttone(...)` | 0〜1 | 歪みのトーン（低い＝暗い） |
| `.tbfilter(...)` | `"tpt"`（既定）/ `"diode"` | フィルタのモデル。`diode` は回路（4 つのコンデンサをダイオードで結合）から導いた非線形モデルで、強く弾くと各段が飽和する。**`tbcut` はレゾナンスのピーク周波数**を指し、低レゾナンスでは暗くなる（実機と同じ性質）。音量は `tpt` よりやや小さいことがある |
| `.tbdrive(...)` | 0.0〜1.0（既定: `tpt` は 0、`diode` は 0.1） | フィルタの飽和量。0 は従来どおりほぼ線形。上げると大きな音が圧縮され、倍音が増える（`tpt` では非対称も加わる）。強くかけると、レゾナンスのピークも抑えられて音が丸くなる |
| `.tbslidecurve(...)` | `"log"`（既定）/ `"hz"` | スライドの形。`log` は半音の空間で指数的に近づく（実機の RC が音程制御電圧にかかるのと同じ。上下で同じ速さ）。`hz` は旧挙動（上がりは速く下がりは遅い） |
| `.tbrel(...)` | 0.002〜0.5 秒（既定 0.015） | ゲートが閉じたあとの音量のリリース。長くすると次のノートと重なり、音がつながる |
| `.tbglide(...)` | 0〜0.2 秒（既定 0） | スライドしないノートでの、音程の短い滑らかさ（数 ms）。実機の音程 CV の滑らかさに相当 |
| `.tbasym(...)` | 0.0〜1.0（既定 0.5、`diode` のみ） | ダイオード対の非対称。偶数次の倍音を作り、芯と噛みつきを増す。0 は対称（地味になりやすい） |
| `.tbdistmix(...)` | 0〜1 | 歪みのウェット／ドライ |
| `.tbdisttype(...)` | `"rat"` / `"tube"` / `"fuzz"` | 歪みの種類 |

コントロールに値が書かれていないノートは既定値に戻ります（前のノートの値が残ることはありません）。

### スライドの仕組み

```javascript
.slide("0 0 1 0 0 0 1 0")
```

3 番目のステップに `1` があると、3 番目の音から 4 番目の音へ滑ります。次のノートがすぐ続くときだけ有効で、間に休符 `~` があると通常の発音になります。


## つまみを連続的に動かす（ノブレーン）

実機の 303 は、演奏しながらカットオフやレゾナンスを手で回します。`.tbcut(sine...)` のようにノートに直接付けると、**値は 16 分音符ごとに 1 回だけ拾われ**、階段状に動きます。連続的に動かすには、ノブ専用の**レーン**を別のブロックで書きます。

```javascript
$: s("tb303ctl").segment(96)       // 1 小節に 96 個の制御点（約 18ms ごと）。各点へ滑らかにランプする
  .tbcut(sine.range(300, 2400).slow(8))
  .tbres(sine.range(0.78, 0.93).slow(12))
  .tbenv(sine.range(0.55, 0.9).slow(6))
  .tbdec(saw.range(0.34, 0.16).slow(32))
  .tbdist(saw.range(0, 0.35).slow(32))
```

- 動かせるのは `tbcut` `tbres` `tbenv` `tbdec` `tbdrive` `tbdist` `tbdisttone`。カットオフは対数（周波数の比）で滑らかに動きます。
- どの Strudel の信号（`sine` `saw` `cosine` `perlin` など）も使え、`.add()` / `.mul()` で重ねられます。例: ゆっくりしたうねり + 2 小節のワブル + 4 小節ごとのひねり。
- **レーンが動かしているパラメータは、ノート側に書かないでください。** ノートに `.tbcut()` などがあると、そのノートの頭ではノートの値が優先されます。
- レーンを書いたコードを評価し直すと、前のコードのレーンは解除されます。
- 制御点が多いほど（`segment(96)` → `segment(192)`）滑らかですが、メッセージも増えます。96 前後で十分です。
- サンプル: `docs/examples/hardfloor-knobs-136.js`（32 小節）、`docs/examples/hamburg-acid-138.js`（48 小節、E マイナー、オリジナル曲。イントロ→グルーヴ→オクターブ→ブレイク→ドロップ→ピーク→アウトロ。diode フィルタ使用）。

## Strudel 標準コントロールとの関係

| コントロール | 303 での扱い |
| --- | --- |
| `gain` `velocity` `postgain` `pan` `orbit` `duck…` など | Strudel の標準処理がそのまま掛かる |
| `lpf` `hpf` `shape` など | 303 内蔵フィルタの**後ろ**に掛かる。303 のフィルタは `tbcut` / `tbres` で操作する |
| `clip` `legato` | 音の長さ（既定は 0.85。1 に近いほどつながる） |
| `attack` `release` `sustain` | 無視される |
| `delay` `room` | 使えるが、プリセットでは使っていない |

## 909 ドラム

```javascript
$: s("bd*4, ~ cp ~ cp").bank("RolandTR909").gain(0.7)
$: s("hh*8, [~ oh]*4").bank("RolandTR909").gain(0.45).cut(1)
```

- ハイハットの開閉を切り替えるには `.cut(1)` を **ハイハット系だけ**に掛けます。キックやクラップと同じブロックに掛けると、ハイハットが鳴るたびに切られます。
- ドラムの音は初回にネットから取得します。オフラインだと鳴りません。

## アシッドのコツ

- **まず 16 ステップ**: `n("0 0 7 4 ~ 2 3 0 0 7 6 4 ~ 3 2 0")` のように 16 ステップで考えると 303 らしくなります。
- **同じ音を繰り返し、時々オクターブ上**（`scale` 使用時は `7`）。メロディを動かしすぎない。度数の目安（マイナー）: `0`=ルート、`2`=短3度、`3`=4度、`4`=5度、`6`=短7度、`7`=オクターブ。
- **音の長さ（連続性）:** `.legato` は 0.85〜0.9 前後がおすすめです。0.5 にすると、音と音の間の約 2 割が無音になり、実機にある音のつながりが失われます（測定: ステップ終わりの音量がピーク比 −39dB、0.85 では −19dB）。`.tbdec`（フィルタのディケイ）も 0.4〜1.2 のように長めにすると、フィルタの掃引が次の音まで続きます。アクセントのステップは掃引が 0.2 秒に固定されるので、アクセントを多用しすぎないでください。
- **accent は 2〜4 個**、**slide は 1〜3 個**を目安に。
- **tbcut を LFO でゆっくり動かす**（`.slow(4)`〜`.slow(16)`）。ライブ中に手で書き換えるのも定番。
- **tbres は 0.8〜0.92**、**tbenv は 0.5〜0.8**、**tbdec は 0.15〜0.3** が出発点。
- 音が痩せたら `tbdist` を 0.3 前後から足す。歪みは音量を変えないようにレベル補正されています。
- **音量バランス**: 303 は単体で 909 のキックより約 3dB 小さい程度に調整済みです。ドラムを `.gain(0.5〜0.75)` に下げ、ハイハットは `.gain(0.3〜0.5)` にすると全体のクリップを避けられます。画面上部の **LIMIT** はマスターのリミッターで、既定でオンです。
