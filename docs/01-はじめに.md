# 1. はじめに

## 起動

```bash
npm install
npm run dev
```

ブラウザで <http://localhost:3000> を開きます（ポートが使用中だと別のポートになります。AI エージェント連携を使うときは 3000 番で開いてください。→ [3章](./03-AI機能.md)）。

## 画面の見かた

| 場所 | 説明 |
| --- | --- |
| **TEMPO** | テンポ（BPM）。変更はすぐ反映され、コードを再評価する必要はありません |
| **DOCS** | アプリ内マニュアル |
| **AI ASSIST** | パターン生成ダイアログ（→ [3章](./03-AI機能.md)） |
| **AGENT OFFLINE / READY** | MCP（AI エージェント）との接続状態。既定はオフ |
| **EVAL** | 編集中のコードを評価して再生（`Ctrl+Enter`） |
| **STOP** | 停止（`Ctrl+.` または `Esc`） |
| エディタ | Strudel 互換のコード入力欄。再生中のステップが緑でハイライトされる |
| OSCILLOSCOPE | 303 の出力波形 |
| OVERDRIVE / DISTORTION | 303 の歪み（RAT / TUBE / FUZZ、DRIVE / TONE / WET-DRY）。コードの `tbdist*` が指定されていればそちらが優先 |
| VCF / ENVELOPE TELEMETRY | 直近のノートのカットオフ・レゾナンス・Env Mod・ディケイ |
| PATTERNS | プリセット（Classic / RAT Drive / Square Wave / Acid Trance / Minimal Sub）。クリックでコードを置き換えて再生 |

## 最初の一音

1. 右の **PATTERNS** から *Classic 303* を選ぶ（または EVAL を押す）。
2. 303 のベースラインと 909 ドラムが同期して鳴ります。
3. コードの数値（`.tbres(0.85)` など）を書き換えて `Ctrl+Enter` を押すと、再生を止めずに切り替わります。
4. `Esc` で停止。

> ブラウザの制限で、最初の再生はボタン押下／キー入力などの操作をきっかけにする必要があります。

## テンポ

- 画面の **TEMPO** で変更するのが簡単です。
- コード側で決めるなら、先頭に `setcps(138/60/4)`（= 138 BPM）または `setcpm(138/4)` を書きます。コード中にこの記述があると、TEMPO を変えたときに数値も書き換わります。

## 保存

エディタの内容は評価のたびにブラウザの `localStorage` に自動保存され、次回起動時に復元されます。別の端末や別のブラウザには引き継がれないので、残したいコードは自分でファイルにコピーしてください。

## 可視化

Strudel 標準の可視化が使えます。

```javascript
$: n("0 0 12 7 ~ 3 5 0").scale("c2:minor").s("tb303").pianoroll()
```

`.pianoroll()` はエディタの背景に描かれます。`.scope()` / `.spectrum()` も同じ場所に表示されます。`_pianoroll()`（コード下のインライン表示）には対応していません。
