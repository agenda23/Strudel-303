# 3. AI 機能

AI 関連の機能は 2 系統あります。どちらも **実験的な補助機能**で、生成されたコードは必ず目で確認してから再生してください。

| 機能 | 用途 | 必要なもの |
| --- | --- | --- |
| [A. パターン生成（AI ASSIST）](#a-パターン生成ai-assist) | 画面内でキーワードや文章からパターンを作る | なし（内蔵）／Gemini API キー（任意） |
| [B. AI エージェント連携（MCP）](#b-ai-エージェント連携mcp) | Claude Desktop などの AI から、このアプリを操作して曲を作る | MCP 対応クライアント、Node.js |
| [C. 外部の AI チャットに頼む](#c-外部の-ai-チャットに頼む場合) | 好きな AI にコードを書かせ、貼り付ける | プロンプトのひな型（下記） |

---

## A. パターン生成（AI ASSIST）

画面上部の **AI ASSIST** を押すと「PATTERN GENERATOR」ダイアログが開きます。

### 使いかた

1. 右側のチップ（Berlin 140 / Hypnotic 138 / Industrial 142 / Detroit 132）を押すか、テキスト欄に作りたい曲調を書く。
2. **GENERATE PATTERN** を押す。
3. 下に生成コードが表示される。
   - **LOAD CODE**: エディタに読み込むだけ（再生はしない）
   - **LOAD & RUN**: 読み込んで、すぐ再生
4. 気に入らなければもう一度 GENERATE。内容は毎回少しずつ変わります。

### 生成方式は 2 つ

| 方式 | 条件 | 内容 |
| --- | --- | --- |
| **内蔵ジェネレータ** | API キー欄が空 | 文章中のキーワードで曲調を選び、乱数で音列・スケール・歪みを変えて組み立てます。ネット接続は不要 |
| **Gemini** | API キーを入力 | Google の Gemini（`gemini-2.5-flash`）に、303 の書き方ルールと依頼文を送ってコードを作らせます |

Gemini が失敗した場合（キー不正、ネットワーク、上限など）は、**自動的に内蔵ジェネレータの結果を表示**します。エラーは出ないので、AI らしくない固定的な出力が続くときはキーを確認してください。

#### 内蔵ジェネレータが反応するキーワード

| キーワード（英語） | 効果 |
| --- | --- |
| `hard` `heavy` `berlin` `fast` `140` `145` `screamer` | ハード系: 140 BPM、アクセント多め、強い RAT 歪み |
| `square` `hollow` `fuzz` | 矩形波、FUZZ 歪み |
| `trance` `goa` `psy` `hypnotic` | 142 BPM、スライド多め、LFO 速め |
| `minimal` `detroit` `deep` `clean` | 132 BPM、カットオフ低め、歪み控えめ |

何も当てはまらなければ 138 BPM のクラシックなアシッドになります。

### Gemini API キーの扱い

- キー欄はパスワード入力で、**そのブラウザタブのセッション中のみ**保存されます（`sessionStorage`）。タブを閉じると消えます。
- 生成のたびに、**依頼文とキーが Google の API に送信**されます（ブラウザから直接）。共有 PC や公開環境では使わないでください。
- キーは自分で取得したものを使い、他人に見せない・コードやリポジトリに書かないでください。

### うまく頼むコツ

- ジャンル／テンポ／質感を短く: 「140 BPM のベルリン系、RAT 歪み強め、アクセント多め」
- 波形（square / saw）、歪みの種類（rat / tube / fuzz）を言葉で指定すると反映されやすい
- 生成後は自分で `tbcut` の範囲や `accent` / `slide` の位置を書き換えて仕上げる

## B. AI エージェント連携（MCP）

MCP（Model Context Protocol）に対応した AI（Claude Desktop など）が、このアプリのエディタにコードを送って再生・停止できます。AI に「ベルリン系のアシッドを作って鳴らして」と頼む使いかたです。

### 全体像

```
AI クライアント ──(MCP / stdio)── MCP サーバー ──(WebSocket 127.0.0.1:3031)── ブラウザのアプリ
```

- MCP サーバー（`mcp/server.ts`）は **自分の PC（127.0.0.1）でのみ**待ち受けます。
- ブラウザ側は既定で無効（オプトイン）です。

### セットアップ

1. **アプリを起動**し、**`http://localhost:3000/?mcp=1`** で開く（`?mcp=1` が必須。一度付けて開けば、以後は `localStorage` に `tb303_mcp = '1'` を設定しても有効にできます）。
   - 接続を許可するのは `localhost:3000` / `127.0.0.1:3000`（開発）と `:4173`（`npm run preview`）のみです。別ポートで開くと接続は拒否されます。
2. **AI クライアントに MCP サーバーを登録**する。

   Claude Desktop（`claude_desktop_config.json`）の例:

   ```json
   {
     "mcpServers": {
       "strudel-tb303": {
         "command": "npx",
         "args": ["-y", "tsx", "<このリポジトリの絶対パス>/mcp/server.ts"]
       }
     }
   }
   ```

   リポジトリ内の `.agents/mcp_config.json` は同じ設定の例です（パスは自分の環境に合わせて変更してください）。手動で起動する場合は `npm run mcp`。
3. クライアントを再起動し、アプリ右上の表示が **AGENT READY**（緑）になれば接続完了です。**AGENT OFFLINE** のままなら [トラブルシューティング](./04-トラブルシューティング.md) を参照。

### 使えるツール

| ツール | 説明 |
| --- | --- |
| `tb303_get_reference` | 303 の書き方・パラメータの早見表を返す。AI が最初に読む用 |
| `tb303_generate_pattern` | スタイル（`classic` / `hard_rat` / `square_screamer` / `trance` / `minimal`）、ルート音（例 `c2`）、スケール（`minor` / `phrygian` / `dorian` / `locrian`）、歪み量（0〜1）からコードを返す。テンポ（`setcps`）入り |
| `tb303_play_live_pattern` | 渡したコードをアプリのエディタに入れて**すぐ再生**する |
| `tb303_stop_live_playback` | 接続中のアプリを停止する |
| `tb303_render_audio_file` | 内蔵 DSP でオフライン演奏し、16 ビット WAV を保存する（既定は `scratch/rendered_303_<時刻>.wav`）。**303 単体の固定 16 ステップ**を鳴らすもので、いまエディタにあるパターンではありません |

### 頼みかたの例

- 「`tb303_get_reference` を読んでから、140 BPM のハードなアシッドを書いて `tb303_play_live_pattern` で鳴らして」
- 「いまのコードより、カットオフの動きを大きくして。再生は止めずに差し替えて」
- 「`hard_rat` スタイル、ルート `d2`、`phrygian` で生成して再生」
- 「停止して」

### 安全面の注意

- `tb303_play_live_pattern` で送られたコードは、**自分で入力したコードと同じようにブラウザ内で実行**されます。信頼できる AI・クライアントだけを接続してください。
- 使わないときは `?mcp=1` なしで開けば、WebSocket には接続しません。
- サーバーは外部ネットワークには公開されません（`127.0.0.1` 限定、Origin は完全一致のみ許可）。

## C. 外部の AI チャットに頼む場合

ChatGPT・Claude・Gemini などのチャットにコードを書かせ、エディタに貼る方法です。以下を最初に渡すと、303 の書き方に沿ったコードが得られやすくなります。

```text
あなたは Strudel（ライブコーディング）でアシッドテクノを書くプロデューサーです。
Roland TB-303 風シンセ（.s("tb303")）と TR-909 ドラムのパターンコードを書いてください。

ルール:
- 先頭に setcps(BPM/60/4) を書く（例: 138 BPM は setcps(138/60/4)）
- 303: $: n("音列").scale("c2:minor").s("tb303") に以下を足す
  .accent("0/1 の列")  .slide("0/1 の列。そのステップから次のステップへ滑る")
  .tbcut(Hz または sine.range(300, 3200).slow(4))  .tbres(0〜1)  .tbenv(0〜1)  .tbdec(0.1〜1.5)
  任意: .tbwave("saw" か "square")  .tbdist(0〜1)  .tbdisttype("rat"|"tube"|"fuzz")
- 音列・accent・slide は同じステップ数（16 ステップ）にそろえる。休符は ~
- ドラム: $: s("bd*4, ~ cp ~ cp").bank("RolandTR909")
          $: s("hh*8, [~ oh]*4").bank("RolandTR909").cut(1)   ← cut(1) はハイハットだけ
- delay / room は使わない
- 出力は実行できるコードのみ（説明文やマークダウンの囲みは不要）

依頼: （ここに曲調を書く）
```

出力をエディタに貼り、`Ctrl+Enter` で再生します。エラーバナーが出たら、その文面を AI に返して直してもらうのが早道です。

## 補足: AI 機能を使わなくても

AI 機能はすべて任意です。プリセット（右の PATTERNS）と [2章](./02-パターンの書き方.md) だけで十分に曲を作れます。
