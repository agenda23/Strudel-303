# 4. トラブルシューティング

| 症状 | 原因と対処 |
| --- | --- |
| 何も鳴らない | 最初はボタン押下／キー入力が必要です。EVAL か `Ctrl+Enter` を押してください。エディタにエラーバナーが出ていないか確認 |
| 303 は鳴るがドラムが鳴らない | サンプルの取得に失敗（オフライン等）。ステータスに「Sample load failed」と出ます。ネットに接続して再度 EVAL |
| キックやクラップが途切れる | `.cut(1)` が全体に掛かっています。ハイハット系だけのブロックに分けてください（[2章](./02-パターンの書き方.md)） |
| スライドが効かない | `slide` は「次のステップへ」滑ります。次の音が続いていること（休符を挟まない）を確認 |
| 303 の音が小さい | Strudel の既定 gain（0.8）が掛かります。`.gain(1.2)` などで調整 |
| `lpf` を付けても 303 の音色が変わらない | `lpf` は 303 内蔵フィルタの後段です。音色は `tbcut` / `tbres` で |
| 「bare n() is read as semitones」の警告 | `n()` を `scale` なしで使っています。`.scale("c2:minor")` を付けるか `note()` を使用 |
| ステップのハイライトが出ない | コードを編集した後は、再評価するまでハイライトが消えます。EVAL してください |
| AI から再生したのに音が出ない | 「click once anywhere」の警告が出ていないか確認。アプリの画面を一度クリックすると音声が解除されます |
| AGENT が OFFLINE のまま | [3章](./03-AI機能.md) の接続手順（`?mcp=1`、ポート 3000、MCP サーバー起動）を確認 |
| AI のパターン生成が内蔵版になる | Gemini API キーが未入力、または API エラーで内蔵の生成器にフォールバックしています |
| 保存したはずのコードが戻る | `localStorage` は評価時に保存されます。評価せず閉じた編集は保存されません |
