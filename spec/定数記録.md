## 次に確定すべきもの（参照音が必要）
1. フィルタの傾きとレゾナンスの上限（`OUTPUT_POLES`、`RES_K_MAX`）
2. アクセント時の掃引長・レゾナンス・音量
3. EnvMod の幅と MEG の曲線
4. 矩形波の形状（実機は非対称）

## フィルタの 2 モデル（`tbfilter`）

| 定数 | 値 | 場所 | 根拠 / 状態 |
| --- | --- | --- | --- |
| モデル | `tpt`（既定、従来の音）/ `diode`（回路から導いた結合・非線形モデル） | `src/dsp/ladder-tpt.ts` / `src/dsp/ladder.ts` | `diode` は未聴感調整。A/B 用に `docs/examples/hardfloor-acid-136-diode.js` |
| ダイオードラダーの小信号応答 | −3dB = 0.1185 ω、位相 −180° = 1.1952 ω、自励発振 k = 18.4、漸近 −24dB/oct（途中 −19） | `src/dsp/ladder.ts` | RC ラダー（等しい結合）を数値解析（文献の「k≈17」と整合）。実機の素子値は未確認 |
| カットオフの対応 | `tbcut` = 位相 −180° の周波数（レゾナンスのピーク） | `src/dsp/ladder.ts` | 実機でつまみがレゾナンスを動かす性質に合わせた。無レゾナンスの膝は約 1/10 下。**従来の `tpt` とは暗さが違う** |
| `RES_K_MAX`（diode） | 18.0 | `src/dsp/ladder.ts` | 臨界 18.4 の少し下。帰還ハイパス 120Hz 込みで res 1.0 は鳴りっぱなしにならない（テスト） |
| 共振の出力補正 | (1+k)^0.55 | `src/dsp/ladder.ts` | 通過帯域の損失（1/(1+k)）を一部だけ戻す。経験値 |
| 入力ドライブ | D = 1 + 14 × `tbdrive`（diode）、D = 1 + 5 × `tbdrive`（tpt） | `src/dsp/tb303.ts` | 経験値。実機は素子電圧に対して D が大きい（強く飽和） |
| 積分 | 台形則 + ニュートン 3 回、4 倍オーバーサンプリング | `src/dsp/ladder.ts` | 実測 0.74µs/サンプル（フィルタ単体）。ボイス全体で予算内（テスト） |
| `DIODE_FILTER_LEVEL` | 0.68 | `src/dsp/tb303.ts` | `tpt` と同程度の音量にするトリム（ブラウザで −2.7dB 差を確認して調整） |
| `TPT_ASYMMETRY` | 0.15 × `tbdrive` | `src/dsp/tb303.ts` | 入力段の非対称（偶数次倍音）。経験値 |

## 第 2 ラウンド調整（聞き比べのフィードバック反映、2026-10-10）

| 定数 | 値 | 根拠 / 状態 |
| --- | --- | --- |
| `DIODE_DEFAULT_DRIVE` | 0.1（`tbdrive` 未指定の diode） | 帯域測定: 飽和は高域を削る（drive .3 で 1.6〜3.2kHz −5dB、.7 で −9dB）。聞き比べで「地味」と評価されたため弱めた |
| `tbasym` / `DIODE_MAX_ASYMMETRY` | 既定 0.5（× 1.5 = 0.75）、最大 1.5 | `T(d) = tanh(d + a) − tanh(a)`（傾き 1 に正規化）。偶数次倍音。200Hz〜3.2kHz が +4〜6dB（asym 0.8〜1.5） |

## ノート間の連続性（第 3 ラウンド、2026-10-10）

| 定数 | 値 | 根拠 / 状態 |
| --- | --- | --- |
| `vegRelease`（`tbrel`） | 既定 0.015 秒（0.002〜0.5） | 以前は固定。長くするとノートが重なる。聞き比べで確定予定 |
| `glide`（`tbglide`） | 既定 0（0〜0.2 秒） | スライドしないノートの短い音程ラグ（実機の音程 CV の RC を想定）。聞き比べで確定予定 |
