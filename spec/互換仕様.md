# Strudel互換仕様（TB-303 ボイス）

## 方針
`s("tb303")` は Strudel の他のサウンドと同じ扱い。superdough に `registerSound` で登録され、標準のチェーンを通る。303固有のものだけ `accent` / `slide` / `tb*` で足す。

## 音程
- `note("c2 eb2")`、`n("0 3").scale("c2:minor")` は Strudel と同じ解決（`freq` > `note`、`octave` で 2^octave 倍、既定は C2）。音名の既定オクターブは Strudel と同じ（`c` = `c3`）。
- `n()` のみ（`note` なし）は旧来の「C2からの半音数」として扱い、初回に警告を出す。

## 長さ
- ゲート長 = イベント長 × `clip`（なければ `legato`、なければ 0.85）。
- `slide=1` のノートはゲートを次の音の頭まで保持（イベント長 × 1.05 以上）。

## スライド（仕様書ルール3）
- ステップ N の `slide=1` は **N から N+1 へ**滑る。N+1 の頭でゲートがまだ保持されていれば、ピッチだけ動かしてMEG/VEGは再トリガーしない。
- 間に休符がある、または前ノートのゲートが閉じている場合は通常の再トリガー（無音にならない）。
- 状態は `hush`/STOP で初期化される。

## 標準コントロールの扱い
| コントロール | 303での扱い |
| --- | --- |
| `gain` `velocity` `postgain` `pan` `orbit` `delay*` `room*` `duck*` `cut` など | superdough のチェーンが適用（303もStrudelの他の音と同じ） |
| `lpf` `lpq` `hpf` `shape` `crush` など | 303内蔵フィルタの**後段**に掛かる（内蔵VCFは `tbcut` / `tbres`） |
| `clip` `legato` | ゲート長（上記） |
| `attack` `release` `sustain` | 無視（303のVEGは固定） |

## 303固有コントロール
`accent`(0/1) `slide`(0/1) `tbcut`(Hz) `tbres`(0–1) `tbenv`(0–1) `tbdec`(秒) `tbwave`(saw/square) `tbslidetime`(秒) `tbdist` `tbdisttone` `tbdistmix` `tbdisttype`。定義は `src/strudel/controls-def.ts` に一元化。`slide` は Strudel 側に同名の未使用コントロールがあるが、再登録して問題なし。

## 表示・操作
- 再生中ステップのハイライト（`hap.context.locations`）。
- `.pianoroll()` はエディタ背景に描画（`#test-canvas`）。`.scope()` / `.spectrum()` も同キャンバス。`_pianoroll()`（インライン表示）は非対応。
- `$:` `_$:` 名前付きブロック `.p()` `all()` `setcps` `setcpm` は動作確認済み。
- テンポUIは `setcpm` を直接呼び、コード中の `setcps(...)` / `setcpm(...)` があれば数値も同期。他のテンポ記法は書き換えない。
